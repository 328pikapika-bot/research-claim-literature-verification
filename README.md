# 科研主张文献核验智能体

[English](README.en.md) | 简体中文

检查科研文本中的可验证主张是否得到文献支持：提取主张、设计检索、组织证据，再输出限定性的判断与引用报告。

## 主要功能

- 从文本或上传的 PDF/TXT/MD 材料提取可逐项核验的主张。源码另有 DOCX 文本解析工具，但尚未接通当前首页和后端保存链路，详见[功能说明](功能说明.md)。
- 按主张检索文献，区分支持、冲突、背景与不确定证据。
- 输出判定、限制、修改建议和引用映射，并提供任务进度与历史。

## 源码与运行入口

`源码/backend/app/pipeline/` 核验流程；`源码/backend/app/core/` 配置；`源码/frontend/web/` 主要界面；`源码/frontend/web_demo/` 静态演示。

Python、Node.js、MongoDB，以及自行配置的模型和文献检索服务。后端依赖见其 requirements 文件，前端依赖见 `源码/frontend/web/package.json`。

后端入口 `源码/backend/app/main.py`；核心配置在 `源码/backend/app/core/config.py` 和 `源码/backend/app/pipeline/workflow_config.py`。

## 配置

检索、模型和数据库配置通过项目环境变量提供。证书辅助脚本使用 `NSTL_PFX_PASSWORD`。前端保留的报告示例已换成合成数据。

配置示例位于源码中的 `.env.example`。真实凭证只保存在本机环境或不跟踪的 `.env` 中。`127.0.0.1` 与 `example.invalid` 为本地/不可解析示例地址，部署前替换为自己的配置。

## 验证与边界

合成样例仅用于演示结构，没有真实文献证据，也不构成科研判断。本次未验证文献服务、真实模型、部署或完整页面交互。
